1. 장치 구성과 조작 체계

1.1 접촉 상태의 변화로 조작을 설계

준비에서는 robot/EE와 입력 owner, calibration, 현재 운전 상태, 시작 자세와 작업물 배치를 확인합니다. 실행에서는 접근·정렬·파지·변형·놓기 사이의 전환을 봅니다. 화면 target이 맞아도 물체가 미끄러지거나 접히는 방향이 달라지면 작업은 성립하지 않습니다.

동작을 단계로 나누면 실패 원인도 달라집니다. 접근 문제는 시야·frame·팔 자세, 파지 문제는 접촉 위치·EE 자세, 변형 문제는 지지점·장력·말단 회전으로 돌아가 살펴봅니다. 모든 실패를 입력 gain으로 해결하려 하지 않았습니다.

2. 유연 물체 조작

2.1 일자 접기: 파지점과 접촉면의 이동

일자 접기에서는 접히는 구간의 가운데를 잡고 위쪽으로 당기는 동작이 유리했습니다. 양쪽 끝만 같은 평면에서 움직이는 것과 달리 중앙을 들어 올리면 접힐 선과 재료가 넘어갈 방향을 만들 수 있습니다. 그다음 gripper를 눕혀 접고, 가운데 부분을 반으로 만든 뒤 위쪽을 접는 순서로 정리했습니다.

여기서 “눕힌다”는 robot orientation 숫자만의 문제가 아닙니다. Gripper가 물체에 닿는 면과 재료가 꺾이는 면을 맞추는 동작입니다. 파지점이 바뀌면 같은 TCP 경로라도 물체가 늘어지거나 비틀리는 형태가 달라졌습니다. 입력 감도보다 먼저 어느 부분을 잡고 어디를 지지할지 정해야 했습니다.

2.2 원형 접기: 고리 형성과 접기의 차이

원형 만들기는 비교적 쉬웠지만, 만들어진 형태를 접는 단계는 어려웠습니다. 말단이 약 180° 가까이 회전해야 했기 때문입니다. 한쪽 팔로 고정하고 다른 쪽을 잡아 넘기는 과정에서 회전 여유와 파지 방향을 함께 봐야 했습니다.

Controller 손목 회전 범위, robot 팔 자세 여유, 물체를 놓지 않고 유지할 접촉 조건은 서로 다릅니다. Clutch로 입력 손 자세를 바꾸어도 robot의 기구적 자세 여유가 자동으로 늘지는 않습니다. 필요하면 재파지·다른 팔의 고정 위치·접근 방향을 바꾸는 대안을 검토합니다.

2.3 이안 매듭: 첫 교차와 나비 모양 형성

이안 매듭의 첫 꼬임은 줄을 X자로 놓고, A를 B 위로 겹친 뒤 B 아래로 넣어 양쪽으로 당기는 순서로 진행할 수 있었습니다. 그러나 리본 형태를 만드는 단계는 훨씬 어려웠습니다. 첫 교차를 수행할 수 있다는 것과 두 loop를 유지하며 리본을 완성한다는 것은 다른 난도입니다.

직선 이동 목표만으로는 loop의 앞뒤 관계와 줄이 통과할 공간을 표현하기 어렵습니다. 고정할 부분·이동할 끝단·손을 바꾸어 잡을 시점으로 나누어 보는 것이 필요했습니다. 이후 개선은 이 공간 관계와 접근 순서를 명확히 하는 방향으로 검토했습니다.

2.4 슬립 매듭: 그리퍼를 펼칠 공간 확보

슬립 매듭에서는 한 팔로 줄을 겹쳐 물방울 형태를 만들고, 반대 gripper를 loop 안에 넣어 연 뒤 끝단을 다시 잡아 바깥으로 당깁니다. 단순히 줄을 통과시키는 것이 아니라 loop 안에서 gripper를 열 수 있는 여유가 필요했습니다.

줄을 당겨 리본 형태를 만드는 동작은 수행했습니다. 남은 줄 길이가 더 길면 난도가 낮아질 것이라는 판단도 남겼지만, 길이를 바꾼 비교 실험 결과와는 구분합니다. 길이는 단순한 물체 사양이 아니라 접근·open·재파지·당김에 필요한 동작 여유를 결정하는 조건이었습니다.

3. 접촉·시야·기록

3.1 삽입과 접촉: 접근 이후 상호작용 정렬

펜뚜껑·랜선·케이블타이처럼 작은 삽입·통과 작업은 대상 근처에 도달하는 단계와 접촉 이후 진행하는 단계를 나누어 기록합니다. 접근 축, 파지 orientation, 실제 끝단 위치, 접촉 시 물체 변형·미끄러짐을 구분해야 합니다. 목표 pose가 맞아 보여도 파지한 물체의 끝단이 같은 위치라는 보장은 없습니다.

접촉 전에는 이동 축과 orientation을 맞추고, 접촉 후에는 물체가 미끄러지거나 비틀리지 않는지 확인하는 순서로 접근합니다. 위치 feedback만으로 접촉력을 알 수 없으므로, 시각 관찰과 실제 물체 상태를 함께 판단해야 합니다.

3.2 조작자 시야와 로봇 피드백

Operator가 직접 보는 정보와 camera 영상, robot feedback은 서로 다른 관측입니다. Gripper가 끝단을 가리면 TCP 위치가 있어도 물체의 정렬을 판단하기 어렵습니다. 시야가 막힌 실패를 단순 위치 오차로 취급하면 같은 접근을 반복하게 됩니다.

이후 작업 정리에서는 어느 단계에서 대상이 가려지는지, 양팔 중 고정 팔이 움직여 시야·장력을 바꾸지 않는지, 놓는 순간 물체가 실제로 지지됐는지를 함께 남깁니다. 접촉이나 장력을 센서로 직접 측정하지 않은 경우에는 시각 관찰과 조작 판단으로 기술합니다.

3.3 조작 영상·수집 episode·학습 실험의 구분

영상은 동작 순서와 물체 상태를 보여주고, episode는 observation·action·시간·device metadata를 제공합니다. 수집 이후 학습과 모델 실행까지 수행한 작업은 Experiments에 따로 연결합니다. Teleoperation만 수행한 시연을 학습 모델 검증으로 바꾸지 않습니다.

동작을 다시 비교하려면 시작 자세·물체 배치·파지 위치·실패 단계를 함께 남겨야 합니다. 영상의 한 장면에서 결과만 비교하면, 접근 조건이 다른 시도를 같은 실험으로 판단하기 쉽습니다.

4. 설계 판단과 배운 점

4.1 Engineering Note: 로봇 경로와 물리 상태를 함께 계획

접기와 매듭에서 가장 크게 배운 것은 같은 로봇 경로라도 파지점·지지점·남은 길이가 바뀌면 다른 작업이 된다는 점입니다. 중앙을 드는 동작, gripper를 눕히는 자세, loop 안에서 열 수 있는 공간은 모두 물체의 상태를 만드는 조건이었습니다.

말단 회전이 부족할 때 gain을 낮추는 것만으로는 해결되지 않았습니다. 입력 reference를 다시 잡을 문제인지, 팔 자세를 바꿀 문제인지, 물체를 재파지할 문제인지를 나눠야 했습니다. 이후에는 “어려웠다”보다 실패한 단계와 바꿀 수 있는 물리 조건을 남기는 데 집중하게 됐습니다.
