양팔에 같은 원형 상대 목표를 입력하고, 실제 TCP의 상대 운동 일치도와 각 팔의 제어기 목표 추종 성능을 분리해 평가했습니다. 측정 코드를 구현하고 반복 시험·결과 분석을 수행했습니다.

## 1. 평가 정의와 시험 구성

### 1.1 평가 질문과 KPI 번호

톤백처럼 두 팔이 하나의 재료를 잡고 움직이는 작업에서는 각 팔의 위치 정확도와 두 팔 사이의 상대 운동이 모두 중요합니다. 저는 양팔에 동일한 원형 상대 목표를 보내고, 실제 TCP 상태를 저장해 두 성능을 분리했습니다.

문서 번호 대응
| 측정 대상 | 과제 요구사항 | 개발 문서

| 양팔 동기 오차 | KPI-2 / PER-2-10 / ≤1 mm | KPI1

| Master–Slave 제어 지연 | KPI-3 / PER-2-20 / ≤50 ms | KPI2

여기서 주지표는 양팔 동기 오차입니다. 코드가 Position Sync RMSE라고 이름 붙인 값은 실제로 양팔 중 큰 tracking RMSE이므로, 이름만 보고 동기 오차와 합치지 않았습니다.

최종 기술설명서·실행 설정 기준
| 항목 | 설정 | 해석

| 운동 | XZ 평면, r=100 mm, T=5 s, 시계 방향 | 회전 목표는 0, 위치 상대 목표를 갱신

## 2. 궤적·계측·평가 수식

### 2.1 원궤적과 누적 상대 목표의 유도

θk=−2πTtk,uk=[r(cos(θk)−1)0rsin(θk)]T시작점 기준 누적 상대 원궤적 — mm
u0=0,pstart=pcenter+[r00]T,p(t)=pstart+u(t)상대 목표가 0에서 시작해 절대 원을 그리는 이유
r=100 mm, T=5 s이며 tₖ=k/60 s입니다. uₖ는 직전 샘플에서 이동할 증분이 아니라 시작점부터의 누적 목표입니다. x=r(cosθ−1)이므로 θ=0에서 x=0, z=0이 되고, 실제 절대 위치는 원 중심에 [r cosθ,0,r sinθ]를 더한 경로가 됩니다.

한 trial은 25초이고 60 Hz 설정으로 1,500개 간격을 사용합니다. 원은 이동 방향과 가감속 방향이 계속 바뀌어 X/Z 응답을 함께 관찰하기 좋습니다. 회전 명령은 0으로 유지해 병진 추종을 주로 평가했습니다.

계산 배열의 u₀=0은 시작 기준이며 실행 루프는 u₁부터 보냅니다. 각 반복에서 양팔 명령을 순서대로 전송한 후 다음 deadline까지 대기합니다. 따라서 궤적 생성의 이산 시각 tₖ와 실제 전송 timestamp를 동일한 값으로 가정하지 않고, pdes·actual과 실제 로그 시각을 평가에 사용했습니다.

### 2.2 명령 스케줄과 로깅·단위

명령은 perf_counter 기반 예정 시각을 따라 갱신하고, logger는 실제 기록 시각과 actual/pdes의 위치·자세를 저장했습니다. 시간표를 생성하는 주기와 실제 SDK 호출·상태 응답의 간격은 다르므로, 100 Hz 로깅 설정을 제어기 servo 주파수라고 표현하지 않았습니다.

최종 KPI1 경로에는 외부 preview·위상 보상·별도 저역통과 필터를 추가하지 않았습니다. 초기 발표자료의 5 Hz 필터 조건을 이 재시험에 옮기지 않았습니다. 원래 유틸리티는 값의 크기로 m/mm를 추정하는 변환을 포함하지만, 0 근처의 mm 값까지 일반적으로 판별할 수 있는 규칙은 아닙니다. 단위는 인터페이스와 시험 범위를 확인한 뒤 해석해야 합니다.

### 2.3 개별 팔 tracking RMSE

ea,k=pa,k−pdes,a,k,Ea=∑i=1N‖ea,i‖2N,Etrack=max(ER,EL)팔별 controller desired tracking
a∈{R,L}이고 위치 세 축의 제곱합을 샘플 평균한 뒤 제곱근을 취합니다. 코드의 trial 대표값은 max(Eᴿ,Eᴸ)입니다. 내부 진단 기준은 0.1 mm이며, 과제 양팔 동기 기준 1 mm와 다른 조건입니다.

### 2.4 상대 위치 offset과 동기 RMSE

da,k=pa,k−pa,0,esync,k=dR,k−dL,k,Esync=∑i=1N‖esync,i‖2N초기 위치만 제거한 양팔 상대변위와 동기 오차
ERMSE=∑i=1N‖ei‖2N,EMean=∑i=1N‖ei‖N,EMax=max(‖ei‖)오차 크기 통계 — RMSE, Mean, Max
각 팔의 최초 위치를 빼면 e_sync=(pᴿ−pᴸ)−(pᴿ₀−pᴸ₀)가 됩니다. 두 팔의 설치 간격에 해당하는 고정 offset만 제거하고, 시간에 따라 두 팔 사이 간격이 얼마나 변하는지 남깁니다. Mean은 오차 벡터 평균의 norm이 아니라 각 샘플 norm의 평균입니다.

평균 RMSE가 1 mm 이내라는 기준과 모든 순간 오차가 1 mm 이내라는 기준은 다릅니다. 순간 편차는 Max를 별도 보고해야 하며, 반복 trial의 Max 평균도 전체 샘플의 최댓값과 구분했습니다.

### 2.5 자세 변화의 비교

va,k=180πLog(Ra,0TRa,k),eori,k=vR,k−vL,k초기 자세에 정렬한 상대회전 벡터의 차이 — degree
각 팔의 초기 회전행렬에서 현재 회전행렬로의 상대회전을 Log로 변환했습니다. 이 회전벡터를 degree로 표시하고 좌우 변화량을 뺍니다. raw Euler subtraction의 ±180° 경계 문제를 피하지만, 두 현재 회전 사이의 geodesic 거리와 동일한 지표라고 부르지는 않습니다.

초기 자세가 다른 두 팔의 절대 orientation이 같다는 시험도 아닙니다. 회전 입력을 따로 주지 않은 조건에서 작은 자세 변화의 일관성을 살피는 보조 지표입니다.

## 3. 평가 방식 변경과 그래프

### 3.1 초기 Mirror·강체 정합에서 평가 기준 변경

초기안은 Left의 X 부호를 뒤집고 Kabsch로 회전·평행이동을 맞춘 뒤 초기 바이어스를 제거했습니다. 정합은 설치 좌표가 다를 때 유용하지만, 평가할 두 궤적 자체에 최적 변환을 피팅하면 실제 궤적 차이 일부도 흡수할 수 있습니다.

최종 재시험 코드에서는 해당 Mirror/Kabsch 경로를 사용하지 않고, 동일한 base 방향의 누적 상대 목표를 양팔에 인가한 뒤 각각의 초기 위치만 제거했습니다. 좌표 정렬을 잘해서 줄어든 잔차와, 실제 양팔 운동이 일치해서 줄어든 오차를 구분하려는 평가 구조입니다. 초기 강체변환 수치를 최종 sync 수치와 직접 비교하지 않았습니다.

### 4.3 달성 여부와 해석

최종 PPT 반복 그래프 기준으로 평균 Sync RMSE는 약0.880 mm로1 mm 이내이며, 20회 중12회가 기준을 통과했습니다. 평균 성능은 목표를 충족하지만 모든 반복 실행에서1 mm 이하를 유지하지는 못했습니다. 따라서 평균 기준 달성과 반복 안정성 확보를 나누어 판단했습니다.

두 팔이 공통으로 늦어지는 구간과 한 팔만 달라지는 구간은 동기 지표에서 다르게 나타납니다. 초과 회차를 추가 분석할 때는 각 팔의actual/pdes와 같은 시간의 상대변위 오차를 나란히 보고, 원의 어느 위상에서 차이가 커졌는지 분리해야 합니다. 평균값만 낮추는 것과 반복 실행 전반에서 기준을 유지하는 것은 다른 개선 목표입니다.

## 5. Engineering Note

### 5.1 Engineering Note

두 궤적을 포개는 정합은 설치 오차를 제거하는 동시에, 평가하고 싶은 운동 차이까지 줄일 수 있었습니다. 이 작업을 통해 측정 전에 제거할 설치 offset과 성능으로 남겨야 할 운동 오차를 정하는 일이 계산식을 구현하는 것만큼 중요하다는 점을 배웠습니다.
